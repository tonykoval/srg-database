The Library’s data (CC BY 4.0)

All data behind these pages, rebuilt by build_library.py (Python standard library only) from the sources listed on the About page. JSON files, one per range of 100 vertices; each also exists as a .js wrapper used by the pages so that they work offline from file://.

  • index.json — one compact line per parameter set (status, count, first comment, families, eigenvalues)
  • refs.json — bibliography; families.json; reasons.json; downloads.json; meta.json (dates, statistics, validation)
  • Curated inputs in data/library/sources/: sage_constructions.tsv (Sage run), ref_links.tsv and ref_urls.tsv (DOI/URL lookups), spence_counts.tsv, ihringer_rows.tsv, our_deposits.tsv, srgdb_catalogs.tsv, counts_literature.tsv

Brouwer’s comments are quoted from his table with attribution; the table remains the authority and should be cited as such.

A. E. Brouwer — Parameters of strongly regular graphs

aeb.win.tue.nl/graphs/srg/srgtab.html — the reference table (26 pages up to 1300 vertices, references, families, many vertices). Individual graphs are described on Brouwer’s graph pages linked from there.

E. Spence — Strongly regular graphs on at most 64 vertices

www.maths.gla.ac.uk/~es/srgraphs.php (University of Glasgow) — 0/1 adjacency matrices, some bzip2-compressed. Counts below were read from the files (the “TOTAL NUMBER” line, or by counting matrices).

F. Ihringer — Many SRGs

math.ihringer.org/srgs.php — large graph6 collections from Godsil–McKay (GM), Wang–Qiu–Hu (WQH) and Kantor-type switching (arXiv 2012.08390, 2107.00076, 2204.04755; program on GitHub). Each count is a lower bound for its parameter set.

Published deposits of A. Kovaľ (Zenodo)

Each record contains the paper and its data archive (graph6 files, certificates, scripts). Overview pages: srg-open-cases / papers, new graphs.

    Also in this repository: catalogs/ — graphs constructed by cascading Godsil–McKay switching for (50,21,8,9) (16,939), (49,24,11,12) and (57,24,11,9) (samples; see index.html). For (57,24,11,9) the 1,122,556 graphs constructed by GM switching have not yet been compared with Ihringer’s 31,490,375.

    Software and other databases

    • SageMath strongly_regular_db — one constructed representative for each parameter set Sage knows; the Library records Sage 10.10’s answer for every row (sage_constructions.tsv, produced by tools/sage_constructions.py).
    • House of Graphs — searchable database of graphs with invariants (Coolsaet, D’hondt, Goedgebeur, doi:10.1016/j.dam.2022.10.013).
    • graph6 format (B. McKay).
