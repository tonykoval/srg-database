What it is

A strongly regular graph srg(v,k,λ,μ) is a k-regular graph on v vertices in which adjacent vertices have λ common neighbours and non-adjacent vertices μ. The Library collects, for every parameter set that A. E. Brouwer’s table lists with v ≤ 1300, what is known: existence status, number of known graphs, constructions, nonexistence reasons, references and downloads — in the spirit of Brouwer’s table, with the underlying data and full citations.

Brouwer’s table is the authority for status. The Library does not change any status. Where the author of this site has published a result (a Zenodo deposit), it is shown next to Brouwer’s entry with its DOI, never in place of it.

Method

  • Rows. Every line of Brouwer’s 26 table pages (1–50 … 1251–1300) is parsed: status symbol (+, −, ?, ! = unique, N! = exactly N), the row colour (cross-checked against the symbol), v, k, λ, μ, the printed eigenvalues rf, sg and the comment. A pair is a parameter set and the complement line printed below it.
  • Spectrum. r, s, f, g are recomputed exactly from (v,k,λ,μ) and compared with Brouwer’s columns. The Krein conditions, the absolute bound and the conference-graph condition are re-evaluated and compared with Brouwer’s labels “Krein1/2”, “Absolute bound”, “Conf”.
  • Counts. Brouwer’s “!” and “N!” give complete classifications. Further counts come from Spence’s data files (read from the files: TOTAL line or the number of matrices), from the text of Ihringer’s page, from published Kovaľ deposits (number of graphs in the deposit), from the GM-switching catalogues of this repository, and from the literature. Counts are never added across sources (overlaps are generally unknown); the headline is the complete count, or else the largest lower bound. A count given for a complement is shown on the pair.
  • Families. The comment of each realised line (and of its complement line) is split at “;” and matched against the family patterns listed on the Families page; labels ending in “?” (a structure that would realise an open row) and “does not exist” statements are not counted. Where a family has one parameter formula, each label’s arguments were checked to reproduce the row.
  • References. Brouwer’s reference page is parsed entry by entry. DOIs he does not print were looked up with the public Crossref API and accepted only for a title similarity ≥ 0.90 with a matching year; four were set by hand after checking (marked in the data). Every entry links at least to Brouwer’s own reference entry.
  • SageMath. For every parameter set, graphs.strongly_regular_graph(v,k,λ,μ, existence=True) and the constructor Sage would use (SageMath 10.10, docker image, no network, one CPU).
  • Seed database. A column for constructions from a seed-graph database is prepared; it is filled by build_library.py as soon as that database’s report exists (currently: pending).

What is deliberately not here

The Library shows only public, citable facts: Brouwer’s table, published papers and preprints, public collections, and the author’s deposited results. It does not show unpublished computations, partial searches, private communications beyond what Brouwer’s table itself records, or graph counts that have not been deposited. For a few parameter sets it shows Brouwer’s status, his comment and the computed spectrum only.

Known open check. This repository’s earlier page (index.html, v ≤ 100) reports 1,122,556 srg(57,24,11,9) graphs constructed by Godsil–McKay switching. F. Ihringer’s collection lists 31,490,375 graphs for the same parameters (2020 and later). The overlap has not yet been checked, so the Library writes “1,122,556 constructed by GM switching (overlap with Ihringer’s collection not yet checked)” and does not call them new.

How to cite

For the status of a parameter set cite Brouwer’s table: A. E. Brouwer, Parameters of strongly regular graphs, https://www.win.tue.nl/~aeb/graphs/srg/srgtab.html (accessed on the date you read it), together with the original paper named in the row.

Licence

The Library’s own data and text (the JSON files, the curated tables in data/library/sources/, the build script and these pages) are released under CC BY 4.0, unless the author decides otherwise. Brouwer’s comments are quoted with attribution and remain his. Third-party collections (Spence, Ihringer, House of Graphs, Sage) are linked and stay under their own terms; no third-party graph file is copied here.

Rebuilding

python3 -I build_library.py (standard library only) rebuilds data/library/ from local copies of the sources; paths are options (--help). tools/enrich_refs.py refreshes the DOI lookups (network), tools/sage_constructions.py the Sage column (inside the SageMath docker image). The pages need no server: open library.html directly.
